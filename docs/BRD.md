# وثيقة متطلبات الأعمال (BRD)

**المشروع:** SubSync Studio (اسم مؤقت)  
**الإصدار:** 1.1 — نطاق MVP معتمد  
**التاريخ:** 10 أكتوبر 2026  
**المنصات:** Windows / macOS / Linux  
**التقنيات الرئيسية:** Electron.js + React.js + TypeScript  
**صيغة الترجمة الأساسية:** SRT

> **حالة الوثيقة:** تم اعتماد قرارات نطاق MVP الخمسة بتاريخ 10 أكتوبر 2026. تبقى تفاصيل التوافق والتوزيع والاسم التجاري بحاجة إلى حسم، ولا تغيّر نطاق MVP المعتمد.

## 1. الملخص التنفيذي

SubSync Studio تطبيق سطح مكتب لإنشاء وتحرير ومزامنة ترجمات الفيديو. يستطيع المستخدم إنشاء مشروع مستقل، وربطه بفيديو محلي أو مصدر فيديو مدعوم، وإضافة مسارات ترجمة بلغات مختلفة، وتعديل النصوص والتوقيت، ومعاينة النتيجة، وتصدير ملف SRT باللغة المختارة.

**القيمة التنافسية الرئيسية:** تجربة مزامنة دقيقة وسريعة باستخدام Timeline مرئي، موجة صوتية (Waveform)، سحب وتغيير حجم مقاطع الترجمة، المحاذاة مع مؤشر التشغيل، التعديل الجماعي، والتراجع عن العمليات.

يعتمد التطبيق نهج **Local-First**: حفظ المشاريع والترجمات محليًا والعمل دون اتصال للوظائف الأساسية المتعلقة بالملفات المحلية.

## 4. نطاق المشروع

### 4.1 نطاق الإصدار الأول (MVP)

1. إدارة المشاريع وإنشاؤها وفتحها وإعادة تسميتها وحذفها.
2. فتح ملفات فيديو محلية وروابط مباشرة لملفات وسائط قابلة للتشغيل فقط؛ لا تكامل مع صفحات مواقع الفيديو أو خدمات البث.
3. إنشاء مسارات ترجمة واستيراد ملفات SRT.
4. إضافة وتعديل وحذف وتقسيم ودمج أسطر الترجمة.
5. Timeline للمزامنة الدقيقة ومعاينة فورية.
6. Waveform وأدوات ضبط توقيت فردية وجماعية.
7. تصدير SRT باللغة المحددة وبترميز UTF-8.
8. واجهة عربية وإنجليزية واتجاه RTL/LTR.
9. Light / Dark / System Theme.
10. تخصيص مظهر الترجمة داخل المشغل.
11. إعداد مسار حفظ المشاريع ومسار تصدير الترجمات.
12. إشعارات داخلية وزر إرسال إشعار تجريبي.
13. عرض رقم الإصدار، وفحص التحديثات تلقائيًا عبر GitHub Releases، وتنزيلها **فقط بعد موافقة المستخدم**، مع خيار الفحص اليدوي.
14. حفظ تلقائي واستعادة حالة التحرير.

### 4.2 خارج النطاق المبدئي / مرحلة لاحقة

- تحويل الكلام إلى ترجمة تلقائيًا (Speech-to-Text).
- الترجمة الآلية بين اللغات.
- المزامنة الآلية مع الكلام باستخدام تحليل صوتي متقدم.
- صيغ VTT وASS وغيرها.
- مزامنة سحابية أو حسابات مستخدمين أو تعاون جماعي.
- تنزيل أو تجاوز حماية المحتوى المقيد أو المحمي بـ DRM.
- استيراد روابط صفحات YouTube أو منصات البث أو استخراج الفيديو من صفحات مواقع الويب.
- دعم أكثر من فيديو رئيسي داخل المشروع الواحد.
- تنزيل التحديثات تلقائيًا دون موافقة المستخدم.

> **قرار معتمد:** روابط الفيديو المقصودة هي روابط وسائط مباشرة قابلة للتشغيل، وليست روابط صفحات مواقع أو خدمات بث. يجب إظهار خطأ واضح عند فشل الوصول أو الترميز أو سياسة CORS أو انتهاء صلاحية الرابط. استخراج Waveform من المصادر البعيدة مشروط بإمكانية الوصول إلى بيانات الصوت؛ عند تعذره يجب إظهار سبب واضح مع استمرار أدوات التوقيت الممكنة.

### 5.4 نظام المزامنة — Smart Synchronization

**قرار معتمد:** هذه هي الميزة الأساسية المميزة للمنتج. يشمل MVP Timeline وWaveform وأدوات مزامنة يدوية سريعة فقط؛ لا يشمل التعرف التلقائي على الكلام أو مزامنة AI.

| ID | الأداة | السلوك المتوقع |
|---|---|---|
| SYNC-01 | Drag Subtitle | سحب مقطع الترجمة لتغيير البداية والنهاية مع الحفاظ على مدته |
| SYNC-02 | Resize Subtitle | سحب حافة المقطع لتعديل البداية أو النهاية |
| SYNC-03 | Snap to Playhead | محاذاة بداية/نهاية المقطع مع مؤشر التشغيل |
| SYNC-04 | Global Offset | تقديم أو تأخير جميع الأسطر بمقدار محدد |
| SYNC-05 | Multi-Select | اختيار عدة أسطر وتعديل توقيتها جماعيًا |
| SYNC-06 | Waveform | عرض الموجة الصوتية للمساعدة في تحديد الكلام |
| SYNC-07 | Frame Stepping | التقدم إطارًا بإطار عند توافر توقيت موثوق للإطارات |
| SYNC-08 | Keyboard Sync | تحديد البداية والنهاية باستخدام اختصارات لوحة المفاتيح أثناء التشغيل |
| SYNC-09 | Overlap Detection | اكتشاف التداخلات وإظهار تحذيرات واضحة |
| SYNC-10 | Live Preview | عرض تأثير أي تعديل فورًا في المعاينة |
| SYNC-11 | Sync Anchors | ضبط نقاط مرجعية لتصحيح الانزياح والتمدد الزمني |
| SYNC-12 | Fine Adjustment | تقديم/تأخير دقيق بالمللي ثانية |

**قواعد التوقيت:**

- تخزين توقيت الترجمة داخليًا بدقة 1ms على الأقل.
- يجب أن تكون النهاية بعد البداية، ولا يسمح بأوقات سالبة.
- يجب التحذير عند تجاوز نهاية الفيديو أو وجود تداخلات.
- دعم تكبير وتصغير Timeline.
- التعديل الجماعي لا يطبق على أسطر غير محددة دون موافقة واضحة.
- جميع تعديلات التوقيت تدعم Undo/Redo.
- دقة تخزين التوقيت لا تعني بالضرورة أن المشغل يستطيع العرض بدقة 1ms؛ ذلك يعتمد على معدل الإطارات ومحرك التشغيل.

مثال:

```srt
1
00:00:01,500 --> 00:00:04,000
مرحبًا بك في SubSync Studio.

2
00:00:04,500 --> 00:00:07,000
ابدأ بمزامنة الترجمة مع الفيديو.
```

**قاعدة مهمة:** اختيار لغة عند التصدير لا يترجم المحتوى تلقائيًا. يجب وجود مسار ترجمة بتلك اللغة أو توفير خدمة ترجمة آلية مستقبلًا.

## 12. معايير قبول رئيسية — Acceptance Criteria

### AC-01 إنشاء المشروع

**Given** المستخدم في شاشة المشاريع  
**When** ينشئ مشروعًا باسم صالح ويختار فيديو مدعومًا  
**Then** ينشأ مجلد مشروع وملف بيانات مستقل ويُفتح المحرر دون اختلاط بمشاريع أخرى.

### AC-02 تعديل توقيت سطر

**Given** وجود سطر ترجمة في Timeline  
**When** يسحبه المستخدم بمقدار زمني محدد  
**Then** تتغير بدايته ونهايته بالقيمة نفسها، مع الحفاظ على المدة، وتنعكس النتيجة في المعاينة ويمكن التراجع عنها.

### AC-03 تغيير مدة سطر

**Given** سطر له بداية ونهاية صحيحتان  
**When** يسحب المستخدم حافته اليمنى أو اليسرى  
**Then** تتغير النهاية أو البداية فقط، وتظهر رسالة واضحة إذا أصبح التوقيت غير صالح.

### AC-04 تصدير العربية

**Given** مشروع يحتوي مساري `ar` و`en`  
**When** يختار المستخدم تصدير `ar`  
**Then** يُنشأ ملف SRT UTF-8 يحتوي النص العربي وتوقيتاته دون استبدال الملف الإنجليزي.

### AC-05 استعادة المشروع

**Given** وجود تعديلات محفوظة  
**When** يغلق المستخدم التطبيق ثم يعيد فتح المشروع  
**Then** تستعاد بيانات المشروع والترجمات والتوقيت وحالة التحرير المحفوظة.

### AC-06 إشعار الاختبار

**Given** المستخدم داخل إعدادات الإشعارات  
**When** يضغط Send Test Notification  
**Then** يظهر Toast ويضاف عنصر إلى مركز الإشعارات دون الحاجة إلى إنترنت.

### AC-07 تبديل اللغة والمظهر

**Given** الواجهة باللغة الإنجليزية وفي الوضع الفاتح  
**When** يختار العربية والوضع الداكن  
**Then** تتغير اللغة والاتجاه والمظهر فورًا وتبقى التفضيلات بعد إعادة التشغيل.

### AC-08 فحص التحديثات

**Given** اتصال متاح ووجود إصدار أحدث متوافق على GitHub Releases  
**When** يفحص التطبيق تلقائيًا عند التشغيل أو يضغط المستخدم Check for Updates  
**Then** تظهر بيانات الإصدار الجديد وخيار تنزيل مناسب للنظام، ولا يبدأ التنزيل إلا بعد موافقة صريحة؛ مع معالجة حالات عدم التوافق أو فشل الاتصال.

## 15A. معايير القبول التفصيلية للقرارات المعتمدة

### AC-MVP-01 — مصدر فيديو محلي

- **Given** مشروع جديد وملف فيديو محلي بترميز مدعوم.
- **When** يختار المستخدم الملف أو يسحبه إلى نافذة الاستيراد.
- **Then** يربط التطبيق الفيديو بالمشروع ويعرض المدة ويتيح التشغيل والتنقل الزمني.
- **And** لا ينسخ الملف الأصلي افتراضيًا ولا يعدّله.

### AC-MVP-02 — رابط فيديو مباشر

- **Given** رابط HTTP(S) مباشر إلى ملف وسائط مدعوم وقابل للوصول.
- **When** يلصق المستخدم الرابط ويؤكد فتحه.
- **Then** يتم تشغيله وربطه بالمشروع مع إظهار حالة التحميل والأخطاء عند الفشل.
- **And** إذا أدخل رابط صفحة ويب عادية، لا يحاول التطبيق استخراج محتواها ويعرض رسالة توضح أن روابط الوسائط المباشرة فقط مدعومة.
- **And** إذا لم تتوفر بيانات الصوت اللازمة للـWaveform بسبب CORS أو قيود المصدر، يعرض تحذيرًا واضحًا دون إيهام المستخدم بأن الموجة الصوتية متاحة.

### AC-MVP-03 — تحرير يدوي دون AI

- **Given** مشروع فيديو لا يحتوي على ترجمة.
- **When** يضيف المستخدم مسارًا عربيًا أو إنجليزيًا.
- **Then** يستطيع إضافة أسطر الترجمة وتعديل النص وأوقات البداية والنهاية يدويًا، دون حساب أو خدمة ذكاء اصطناعي.

### AC-MVP-04 — Timeline والمزامنة الدقيقة

- **Given** سطر ترجمة ظاهر على Timeline.
- **When** يسحب المستخدم جسم السطر بمقدار 250ms.
- **Then** تتحرك البداية والنهاية بمقدار 250ms مع بقاء المدة ثابتة.
- **And** تنعكس التغييرات في المعاينة ويمكن التراجع عنها وإعادتها.
- **And** يمنع التطبيق إنتاج توقيت سالب أو نهاية لا تتجاوز البداية.

### AC-MVP-05 — Waveform والأدوات اليدوية

- **Given** ملف فيديو محلي يمكن استخراج بيانات الصوت منه.
- **When** يفتح المستخدم Timeline ويختار عرض Waveform.
- **Then** تظهر الموجة الصوتية متوافقة مع محور الزمن، ويمكن التكبير والتصغير والمحاذاة مع مؤشر التشغيل وتعديل التوقيت بدقة.
- **And** لا يفترض التطبيق أن قمم الموجة تساوي حدود الكلام تلقائيًا.

### AC-MVP-06 — مشروع واحد / فيديو واحد / عدة لغات

- **Given** مشروع مرتبط بفيديو واحد ومسار ترجمة عربي.
- **When** ينشئ المستخدم مسارًا إنجليزيًا أو يستورد `en.srt`.
- **Then** يظهر المساران تحت المشروع نفسه ويحتفظ كل منهما بنصه وتوقيته المستقل.
- **And** عند محاولة إضافة فيديو رئيسي ثانٍ، يوضح التطبيق أن المشروع يدعم فيديو واحدًا ويتيح استبداله بتأكيد أو إنشاء مشروع جديد.
- **And** تصدير العربية لا يغير الملف الإنجليزي، والعكس صحيح.

### AC-MVP-07 — فحص تحديث تلقائي مع الموافقة

- **Given** اتصال بالإنترنت وإصدار أحدث متوافق منشور على GitHub Releases.
- **When** يبدأ التطبيق ويكتمل فحص التحديث التلقائي.
- **Then** يظهر إشعار بالإصدار وملاحظات الإصدار وخيارا **تنزيل** و**لاحقًا**.
- **And** لا يبدأ تنزيل أي حزمة قبل اختيار **تنزيل** صراحةً.
- **And** عند اختيار **لاحقًا** يواصل المستخدم العمل دون تنزيل أو إغلاق إجباري.
- **And** عند الموافقة يظهر تقدم التنزيل، وتُعالج أخطاء الشبكة بوضوح.
- **And** لا يُثبَّت التحديث أو يُعاد تشغيل التطبيق دون تأكيد وحفظ آمن للتعديلات.
- **And** يظل خيار **Check for Updates** اليدوي متاحًا في الإعدادات.

### AC-MVP-08 — تصدير SRT مستقل لكل لغة

- **Given** مشروع يحتوي على مسارين `ar` و`en` مع توقيتات ونصوص مختلفة.
- **When** يختار المستخدم تصدير `ar` إلى مسار الحفظ المحدد.
- **Then** ينتج ملف SRT صالح بترميز UTF-8 وترقيم متسلسل وتوقيت `HH:MM:SS,mmm`، دون تعديل المسار الإنجليزي أو تصديره بالخطأ.
